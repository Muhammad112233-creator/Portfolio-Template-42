A high-contrast, motion-first portfolio template inspired by award-winning creative-director sites — rebuilt from scratch with **Nuxt 3 + Vue 3 + Tailwind CSS v4 + GSAP ScrollTrigger + Lenis smooth scroll**. Every section, animation, cursor interaction, and responsive breakpoint mirrors the reference experience, with completely original content and AI-generated assets.

</div>

- **Name / role:** edit `pages/index.vue` (hero title + intro lines) and `nuxt.config.ts` (page `<title>` + meta).
- **Images:** swap anything in `public/images/` — keep the same filenames for zero code changes.
- **Colors:** change `--blue` / `--bluelight` in `assets/css/main.css` (`:root` + `html.dark`).
- **Socials / email:** edit `components/SiteFooter.vue` and `pages/contact.vue`.
- **Clock city:** change `Asia/Karachi` in `SiteFooter.vue` to any IANA timezone.
